# CIDM 6395 Capstone Project Proposal

## A Web-Based Salon Management and Business Analytics System

### Project Overview

The proposed capstone project is the design and development of a web-based salon management and business analytics system for a fictional small salon and spa. Small service-based businesses manage interconnected information related to customers, employees, services, appointments, and payments. The purpose of this project is to demonstrate how an integrated information system can organize this information, support daily business operations, provide useful business insights and protect business and customer data. The project will integrate competencies from Data Management (DM), Business Analytics (BA), Software Systems (SS), and Cybersecurity and Networking (CN).

### Data Management (DM)

The Data Management component will establish the information architecture for the system. Business requirements and rules will be translated into an Entity-Relationship Diagram (ERD) containing entities such as Customer, Employee, Service, Service Category, Appointment, Payment, Review, and User Account. The relational database will be normalized to Third Normal Form (3NF) and implemented using MySQL. SQL will be used to create and populate the database and to retrieve information through queries involving joins, aggregation, subqueries, and other relational database operations.

### Business Analytics (BA)

The Business Analytics component will use data generated by the salon system to examine business performance and customer activity. Data visualization techniques will be used to analyze metrics such as appointment volume, service popularity, revenue trends, customer retention, transaction values, and employee or service utilization. The analysis will produce visualizations and documented findings that demonstrate how operational data can be transformed into information that supports business decision-making.

### Software Systems (SS)

The Software Systems component will transform the database design into a functional web application. The application will provide customer-facing features for viewing services, creating an account, logging in, and managing appointments. An administrative interface will provide authorized users with functionality for managing customers, services, employees, appointments, and related business information. The application will use a web-based frontend, a Python backend, and a MySQL relational database to demonstrate the integration of user interfaces, application logic, and persistent data.

### Cybersecurity and Networking (CN)

The Cybersecurity and Networking component will focus on protecting the completed information system. Security controls will include authentication, password hashing, role-based authorization, input validation, protected configuration information, and appropriate access restrictions. A network and security architecture diagram will document communication among users, the web application, application services, and the database. Basic security testing will be performed to evaluate selected controls and identify potential application risks.

### Final Artifact

The final synthesis artifact will be a functional salon management web application that integrates the four competency areas and is supported by source code, database files, sample data, documentation, and instructions for execution. The completed project will demonstrate the progression from business requirements and database design to data analysis, application development, and system security. All project artifacts, documentation, source files, and supporting materials will be maintained within a single GitHub repository.
